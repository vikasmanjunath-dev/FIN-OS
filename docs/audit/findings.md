## Baseline command evidence

Initial raw outputs are saved in `docs/audit/baseline/`. Results from the first sandboxed run:

- `npm test`: 4 failed, 320 passed, 6 skipped, 31 warnings, 470 errors in 28.44s. Most errors are fixture setup `PermissionError` while binding `127.0.0.1`; 4 named failures are in `test_csp.py`, `test_inline_handlers.py`, `test_mobile_layout.py`, and `test_perf_budget.py`.
- `npm run check`: passed. Search index is current; static audit reports 0 issues for tokens, links, search, JS, IDs, routes, and secrets.
- `npm run smoke`: blocked by sandbox `PermissionError` binding its local server.
- `cd mobile && npm test` on default Node 20: unsupported `.mts` extension. The quoted glob was removed; use Node 24 from CI. Full mobile run is currently in progress.
- `cd mobile && npm run typecheck`: passed (`tsc --noEmit`).
- `cd mobile && npm run lint`: attempted to install absent ESLint dependencies, then emitted offline/dependency-validation messages. The CLI modified `mobile/package.json`; that incidental edit was immediately reverted. Lint remains unverified.
