## What was built
- `mobile/scripts/extract-learn.py`: deterministic extractor (BeautifulSoup, no clock/network, sorted keys). `python3 mobile/scripts/extract-learn.py` writes; `--check` fails if committed output differs. Produces `mobile/content/learn/{manifest,review}.json` + one JSON per lesson, the generated `mobile/lib/learnContent.ts` (static requires so Metro bundles offline), and `docs/agent-notes/learn-review.md`.
- 25 pages mapped: 22 readable lessons (15 `learn-*`, 5 `insight-*`, `finance101`, `principles`) and 3 interactive-only pages (`foundations`, `investor-mindset`, `investor-profile`) that are NOT flattened: they show a card linking to the matching phone tool (`/tools/dna` for the mindset pages; foundations has no phone equivalent). Excluded with reasons in the manifest: `simulator-guide`, `train-mindset` (redirect stub), `mindset-sim*`. Lesson ids for the 15 `learn-*` pages equal the website's `finos_learned_modules` ids (`mutual_funds`, `money_market`, ...). The website has no `learn-tax` page although `js/learn-ai.js` lists a `tax` module.
- Content blocks: headings, paragraphs, lists, tables, callouts (tip/warning/fact/note), kickers (LEVEL/MODULE badges). Website UI chrome ("SYSTEM: ONLINE", "Swipe to...") is dropped; text is never rewritten.
- Review: 32 flagged passages with quote, why, current rule, confidence in `docs/agent-notes/learn-review.md` (generated; table lives in REVIEW_ITEMS of the extractor). Each is flagged `needsReview` in the JSON; the reader shows a lesson banner and a gold "check before relying" box under the passage. The script fails if an anchor stops matching.
- Reader UI: `app/learn/index.tsx` (progress, search, continue/up next, categories), `app/learn/[id].tsx` (lesson, banner, related tool, mark learned / undo, next lesson), `components/LearnBlocks.tsx` (all text via `LText` with `maxFontSizeMultiplier=2`, themed tokens only).
- Progress: `lib/learn.ts` (pure) + `lib/learnStorage.ts`. Writes `finos_learned_modules` in the website's shape `{id: {completed_at, attempts, last_visited}}`, tested against the real `_markCompleted` from `js/learn-ai.js` run in a vm. Extra phone-only key `finos_learn_opened` ({id: ISO}) drives the Continue card; it is not part of the website shape.
- Health Score Knowledge pillar: `knowledgePoints = min(6, floor(count*0.43))` + streak points, cap 10; `TrackerData.learnedModules` loaded in `trackerStorage.ts`. The golden test evaluates the website's own formula text out of `js/finos-health-score.js`.

## Honest limits and findings
1. **Website bug found (not fixed, outside my area):** `js/finos-health-score.js` reads `finos_learned_modules` with `Array.isArray(learned) ? learned.length : 0`, but `js/learn-ai.js` writes an OBJECT. So on the website, reading lessons never earns Knowledge points. The phone counts the entries of the object (array form still counts its length exactly like the website). Result: a phone Health Score can be up to 6 points higher than the website's for the same data until the website reads `Object.keys`. Suggested website fix: `const moduleCount = Array.isArray(learned) ? learned.length : Object.keys(learned || {}).length;`. Pinned by a test so the divergence is deliberate.
2. The review is from my own knowledge (no live web access); every row must be confirmed against RBI/SEBI/CBDT primary sources by a human before a flag is removed. Confidence is stated per row. Largest items: stale CPI (6-7% vs about 2-3% in FY 2025-26), USD/INR 83.50, 100x forex leverage for residents, the "20-year loan in 12 years" prepayment claim (computed: about 16.3-16.9 years), arbitrage-fund tax, SGB availability, digital gold conflated with SGB, FD/G-Sec/T-bill rates.
3. Passages with interactive widgets on the website (sliders, charts) lose the widget; their default output values stay in the text (for example "Doubles in: 18 Years" on `principles`). Lessons with such widgets say so at the top.
4. Hindi lesson text is not translated (content is English from the website); only the chrome strings below are.
5. Light theme: verified with `theme-audit.py` (0 low-contrast) and the smoke test (dark + light, empty + populated) but the Playwright screenshot I looked at was dark; the audit script drove the light check.
6. Search is word-prefix over title, summary and body of the bundled lessons (on-device, no network). No new host, permission or SDK: no privacy-guard change.
7. `mobile/.expo/types/router.d.ts` was regenerated by `expo start`; I restored it. Add the `/learn` and `/learn/[id]` routes there when you regenerate.
