# Learning loop: spaced review, Quick review, weekly review

- **Spaced review** (`lib/reels/spaced.ts`): each answered reel has a stage 0 to 4 (`n` in the watched record, written by `recordWatched`). A right answer steps up and the next refresher is due after 1, 3, 7, 21, 60 days; a miss goes back to stage 0 (due after one day, and the ranker still puts a missed question first). Data from before stages: a right answer counts as stage 2 (a week), a miss as stage 0. The ranker offers a "refresher" only when a reel is due (`isDue`). Reels health shows how many reels sit at each stage.
- **Quick review** (`app/learn/review.tsx`, `lib/reels/recall.ts`): five due questions, taken from different topics in turn (interleaving), options in the reels' scrambled order. After an answer the person writes the reason in one line before the reel's reason is shown (teach it back; skippable; never stored). Each answer goes through `recordWatched`, so stages move. The Home card shows "N questions to review"; Learn has a card.
- **Weekly money review** (`app/learn/weekly.tsx`, `lib/reels/weeklyReview.ts`, `lib/reelsWeeklyStorage.ts`): a win, a gap and one move for next week, one entry per ISO week, last eight kept, with last week's move on top. Key `finos_session_reels_weekly` (never synced; in the privacy registry; reset together with the challenges part of "What the reels know about you").
- Tests: `__tests__/reels-learning.test.mts`.
