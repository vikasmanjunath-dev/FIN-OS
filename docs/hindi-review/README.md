# Hindi review sheets for Money Reels

Generated by `npm run reels:hindi` (do not edit by hand; edit `Reviewer fix` in a copy, and send the copy back). Nothing here changes a reel.

**Scope:** 177 live reels and 50 draft reels waiting behind the review gate, each with its "How this is worked out" note, plus 23 money facts: 4764 texts in all. 0 reels have both sign-offs in `lib/reels/review.ts`; the rest do not. The Hindi was written by a machine and has not been read by a person.

## What you are asked to do

1. Open the sheet for a topic (`topic-*.csv`, UTF-8; in Excel use Data > From Text/CSV if the Hindi looks broken).
2. For every row read the Hindi next to the English. Does it say the same thing, and is it how a person would say it on a phone screen? Write a better line in **Reviewer fix**, or put a tick (or Y) in **OK**.
3. Rows with a flag in the **Lint flags** column were noticed by a program. `!` is probably wrong; `?` is only worth a look. A flag is a pointer, not a verdict: you may decide the Hindi is fine.
4. Settle the words in `glossary.csv` (fill in **Reviewer decision**), then the spellings in `spelling.csv` and the two-ways terms in `variants.csv`. One decision there fixes many rows.
5. Do not mark a reel signed off in a sheet. A sign-off is a line in `lib/reels/review.ts` made by the content owner after both readers are done; `reels-index.csv` shows which reels have one.

## Files

| File | What it is |
|---|---|
| `topic-<topic>.csv` | Every text of every reel in that topic: reel, release state, gate state, where on screen, English, Hindi, flags, and two empty columns for you |
| `reels-index.csv` | One row per reel: whether it has the Hindi and compliance sign-offs, how many texts are flagged |
| `glossary.csv` | The Hindi proposed for each recurring term, other forms that are fine, forms to replace, and how often each is used now |
| `variants.csv` | Terms written in more than one way, with counts from the reels and from the app’s own screens |
| `spelling.csv` | Words spelled two ways (nukta or chandrabindu), with counts |

## What the checks cannot do

- They cannot tell whether a sentence sounds natural. That is your job and the reason this review exists.
- They compare the Hindi with the English only for numbers, ₹, % and lakh/crore/thousand. A sentence that says something different in words will not be caught.
- The glossary is a proposal. Where the app’s own screens (`lib/i18nHi.ts`) and the reels disagree (for example आपातकालीन निधि against आपातकालीन फ़ंड), `variants.csv` shows both counts.
- Reels built from a person’s own figures (“Your Number”) fill their sentences at run time from templates in `personal*.ts`; those sentences are not in these sheets.
