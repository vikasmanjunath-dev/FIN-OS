If you switch this on, Arya keeps short examples of some of your questions on this device, so you can send them to us if you choose.

  • What is kept: only questions that Arya's on-device check marked as possibly asking for a personal investment decision or something illegal. Numbers, amounts, e-mail addresses, UPI IDs and similar details are blanked out before anything is saved. At most 50 examples.
  • Where: only in this browser, on this device. Nothing is sent automatically, ever.
  • Names are not found automatically. Please read each example below and delete any that contain a name or anything personal before you send a file.
  • What we do with a file you send: check where Arya gets things wrong and improve it. We keep examples for 90 days (draft), never sell them and never use them for ads.
  • Delete: delete one example, or all of them, below at any time. Switching this off stops saving; delete the examples to remove them.

इसे चालू करने पर Arya आपके कुछ सवालों के छोटे उदाहरण इसी डिवाइस पर रखता है, ताकि आप चाहें तो उन्हें हमें भेज सकें।

  • क्या रखा जाता है: सिर्फ़ वे सवाल जिन्हें Arya की डिवाइस पर चलने वाली जाँच ने "निजी निवेश सलाह माँगने वाला" या "गैरकानूनी" माना। नंबर, रकम, ई-मेल, UPI ID जैसी जानकारी सहेजने से पहले मिटा दी जाती है। अधिकतम 50 उदाहरण।
  • कहाँ: सिर्फ़ इसी ब्राउज़र में, इसी डिवाइस पर। अपने-आप कुछ भी कभी नहीं भेजा जाता।
  • नाम अपने-आप नहीं मिटते। फ़ाइल भेजने से पहले नीचे हर उदाहरण पढ़ें और जिसमें नाम या कोई निजी बात हो उसे मिटा दें।
  • भेजी गई फ़ाइल का हम क्या करते हैं: देखते हैं कि Arya कहाँ गलती करता है और उसे सुधारते हैं। उदाहरण 90 दिन रखे जाते हैं (मसौदा), कभी बेचे नहीं जाते और विज्ञापन में इस्तेमाल नहीं होते।
  • मिटाना: नीचे किसी भी समय एक या सभी उदाहरण मिटा सकते हैं। इसे बंद करने से सहेजना रुकता है; उदाहरण हटाने के लिए उन्हें मिटाएँ।

(यह हिन्दी पाठ मसौदा है; किसी हिन्दी जानकार से जँचवाना बाकी है।)
