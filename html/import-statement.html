Import a bank statement

Bring your transactions in from a statement file. The file is read on this device and never uploaded. Your account number and name are not read at all.

1. Get the file

In your bank's net banking, download the account statement as CSV (some banks offer Excel: open it and choose Save As → CSV). Account Aggregator JSON that your provider has already decrypted also works. PDF statements cannot be read here.

2. Choose it

Your imports

Each import can be undone, which removes exactly the transactions it added and nothing else.
