# FIN·OS Mobile

Expo (SDK 57) / React Native 0.86 app that mirrors the FIN·OS website's trackers and portfolio on a phone.
Full documentation: [`../docs/MOBILE_APP.md`](../docs/MOBILE_APP.md).

```bash
npm install --legacy-peer-deps
npx expo start --web --port 8082     # or: npm run ios / npm run android
```

- Backend: start `../arya-ai/start.sh` (port 7475). Set a different host in the app's Settings if it isn't on this machine.
- Cloud login/sync is optional: copy `.env.example` to `.env` and fill in a Supabase URL + anon key. Without it the app runs in guest mode. `.env` here already points at the website's project; see `../supabase/README.md` for the SQL to run first.
  Run `../supabase/holdings.sql` in that project first.
- Checks: `npm test` (1,371 tests on Oct 22 2026, all passing: parity against the website's JS, statement import, tracker-sync merge and Supabase adapter, storage, privacy and storage-key guards, search index, Hindi table) `npm run typecheck`, and `npm run lint` (ESLint 9, no warnings allowed). `npm run reels:check -- <reel-id>` prints the author checklist for one Money Reel (`../docs/REELS-AUTHORS.md`). `python3 scripts/smoke-routes.py` opens every screen in the web preview, empty and populated, dark and light.
- Device builds: `eas.json` has development / preview / production profiles (none run yet). Sideload APKs (1.0.0 to 1.2.0) are built on this machine, not by EAS, with `plugins/withLocalReleaseSigning.js`; see `../docs/RELEASE_RUNBOOK.md` section 4b. `android/` is generated by `expo prebuild` and is git-ignored.
- Layout: `app/` screens · `components/` · `hooks/` · `lib/` pure logic and storage · `constants/` endpoints and theme · `content/` bundled lesson and insurance text (generated by `scripts/extract-learn.py` and `scripts/extract-insurance.py`, each with `--check`).
