# Model card: router 0.5.1 (candidate; NOT an active guard; shadow default is still 0.4.1)

**Purpose** as 0.4.1: route a message into 13 intents and flag the two high-risk intents (advice_seeking, evasion_request) with a guard. Architecture: TF-IDF LR + mxbai-embed-large LR blend (embed weight 0.5), guard = predicted class in the two risk classes OR P(advice)+P(evasion) >= 0.35.
**Training data** train 610 + train_extra 1,354 + train_extra2 801 (writers X, Y, Z, written after the sealed test_v7 failure: broad out_of_scope variety, non-finance "should I / which is best" phrasing, minimal pairs, balanced finance positives) + valid + dev (805 incl. dev3, 288 risky; used to choose settings) in the final refit. The settings (weight, C, threshold) were chosen on dev + dev3 only, by the same rule as before (highest threshold with dev recall >= 0.99).
**Sealed test_v8 (2026-10-26, six new blind writers v81-v86 with a brief that contained no example sentences; scored once, TRACKER C22):** 846 messages (351 risky, 495 benign incl. tricky look-alikes). macro-F1 **0.9506** (CI 0.932-0.964: PASS), note-level false alarm **4.85%** (24/495, upper 95% bound 6.75%; gate 5% point: PASS), guard recall **0.9886** (347/351, Clopper-Pearson lower bound **0.974**, gate 0.98: MISSED by 0.006). By language: en 0.971, hi_en 0.966, hi 0.928. Weakest intents: out_of_scope 0.860, document_help 0.923, personal_money_summary 0.923. Misses: indirect or hypothetical requests (false Form 15H, a fake salary slip for a relative, "tell me exactly how to split my savings") and Hindi advice questions about NPS or loan prepayment.
**Versus 0.4.1:** on the older sealed test_v7 (now diagnostic for 0.5.x) 0.4.1 had F1 0.9448, recall 333/333, false alarm 11.85%; 0.5.1 had F1 0.956, recall 329/333, false alarm 4.3%. The recall/false-alarm trade-off is a property of the model, not only of the threshold: on test_v8 (information only, not used to choose anything) thr 0.10 -> recall 351/351, false alarm 21.4%; 0.15 -> 350/351, 15.6%; 0.20 -> 349/351 (lower bound 0.982), 11.3%; 0.30 -> 348/351, 6.7%; 0.35 -> 347/351, 4.9%; 0.40 -> 346/351, 3.4%; 0.50 -> 345/351, 2.8%. A recall lower bound of 0.98 and a false alarm of 5% do not hold at the same threshold; a note level (cheap, can accept ~11-16%) and a steer/block level (needs ~3-5%) would use different thresholds (founder decision F3).
**Limits** all text is agent-written; test_v8 has 495 benign messages (< the 600 asked for block level); hi (Devanagari) is the weakest language; 0.5.1 was shaped by the failures of test_v7, so v7 no longer counts for it.
**Files** `embed_lr.npz`, `tfidf_lr.joblib` (git-ignored; retrain with `train_router_v2.py --version 0.5.1 --overwrite` on the committed data), `tfidf_head.json/npz` no-pickle head, `eval.json`, `SHA256SUMS`. Embeddings: Ollama `mxbai-embed-large:latest`, digest `468836162de7`.
